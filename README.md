# 中国古典文学问答系统

一个基于BM25检索和规则匹配的开放领域问答系统，支持对中国古典文学知识的交互式问答。

## 📁 项目结构

```
ASK-ANSWER/
├── data/
│   └── knowledge_base.jsonl    # 知识库文件（101条经典段落）
├── src/
│   ├── retriever.py            # BM25检索器
│   ├── reader.py               # 阅读器（支持BERT和规则匹配）
│   └── qa_system.py            # 问答系统集成模块
├── templates/
│   └── index.html              # Web界面模板
├── app.py                      # Flask Web应用入口
├── main.py                     # 命令行界面入口
└── README.md                   # 项目说明文档
```

## 🚀 快速开始

### 环境要求

- Python 3.8+
- 依赖包：rank_bm25, jieba, flask, transformers, torch（可选）

### 安装依赖

```bash
pip install rank_bm25 jieba flask
# 如果要使用BERT模型，需要额外安装
# pip install transformers torch
```

### 运行系统

**方式一：命令行界面**

```bash
cd ASK-ANSWER
python main.py
```

**方式二：Web界面**

```bash
cd ASK-ANSWER
python app.py
```

然后访问 `http://127.0.0.1:5000`

## 🧠 系统架构

### 1. 检索器 (Retriever)

基于 **BM25** 算法实现，配合 jieba 中文分词：
- 对知识库建立倒排索引
- 支持快速关键词检索
- 返回 top-k 相关段落

### 2. 阅读器 (Reader)

**模式一：规则匹配模式（默认）**
- 基于正则表达式提取答案
- 识别"曰"、"道"、"谓"等关键词后的内容
- 无需依赖深度学习环境

**模式二：BERT模型模式（可选）**
- 使用 `bert-base-chinese` 预训练模型
- 需要网络下载模型（约400MB）
- 支持更准确的语义理解

### 3. 知识库 (Knowledge Base)

包含15种中国古典文学经典文献。
